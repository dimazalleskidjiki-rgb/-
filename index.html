БЫСТРЫЙ СТАРТ

Как установить игру?

  1. 1
    Скачай файл

    Нажми «Скачать APK», когда ссылка будет добавлена администрацией.

  2. 2
    Проверь файл

    Скачивай установщик только из официальных источников проекта.

  3. 3
    Установи приложение

    Открой APK и следуй подсказкам Android. Разрешай установку только если доверяешь источнику.

  4. 4
    Запусти YARD RP

    Следуй инструкциям проекта для входа в игру.

!Если файл ещё не опубликован, кнопка скачивания не начнёт загрузку. Сначала добавь реальные ссылки на APK и лаунчер.
