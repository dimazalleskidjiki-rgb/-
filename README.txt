YARD RP — сайт скачивания (Android / Spck Editor)

Файлы:
- index.html — структура сайта
- style.css — дизайн и адаптация под телефон
- script.js — меню и ссылки скачивания/соцсетей

Как открыть в Spck Editor:
1. Создай папку проекта YARD-RP.
2. Создай в ней три файла с указанными именами.
3. Скопируй содержимое каждого файла из архива в соответствующий файл.
4. Открой index.html через Preview.

Как добавить настоящие ссылки:
1. Открой script.js.
2. В самом верху найди объект CONFIG.
3. Впиши прямые ссылки в кавычки:
   apkUrl: "https://.../yard-rp.apk"
   launcherUrl: "https://.../yard-launcher.apk"
   telegramUrl: "https://t.me/..."
   forumUrl: "https://..."
4. Сохрани файл и проверь кнопки.

Важно:
- Пока реальных файлов APK/лаунчера нет, кнопки покажут подсказку, а не начнут скачивание.
- Для скачивания нужны настоящие прямые ссылки на файлы или страницы загрузки.
- Не указывай выдуманные IP, статус сервера, размер игры и системные требования: обнови их в index.html после тестирования.
- Google Fonts используется для шрифта; без интернета сайт всё равно откроется с запасными шрифтами.

Публикация через GitHub Pages:
1. Создай GitHub-репозиторий, например yard-rp.
2. Загрузи index.html, style.css и script.js в корень репозитория (не внутрь дополнительной папки).
3. В репозитории открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку main и папку /(root), затем Save.
6. Подожди, пока GitHub Pages опубликует сайт, и открой адрес, который появится в Settings → Pages.
7. Если видишь 404, проверь, что имя файла ровно index.html и он лежит в корне.

Безопасность:
Публикуй только APK, который ты имеешь право распространять. Игрокам лучше скачивать установщики только из официального канала проекта.
